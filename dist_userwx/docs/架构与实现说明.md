# EDA 实验一实现说明

## 1. 实验目标

实验一不是做一个通用绘图软件，而是做一个 PCB 封装编辑器。最终产物必须能回答下面几个问题：

1. 一个封装由哪些对象组成。
2. SMD 焊盘和 THT 引脚有什么区别。
3. 焊盘尺寸、间距、钻孔、阻焊开窗怎么保存。
4. 封装文件如何写盘和重新读取。
5. 元件库如何组织并供实验二加载。

本项目的实现主线是：

```text
Footprint 数据模型
    -> 画布显示和鼠标编辑
    -> 自定义 .fp 文件
    -> footprints 元件库
    -> 实验二按 footprintId 创建元件实例
```

## 2. 模块划分

### `src/App.cpp`

程序入口，只负责创建主窗口，不承载业务逻辑。

### `src/FootprintModel.h/.cpp`

纯数据层，不依赖 wxWidgets 控件。

主要对象：

- `Footprint`：一个完整封装。
- `PadItem`：SMD 焊盘或 THT 引脚。
- `SilkLine`、`SilkRect`、`SilkArc`、`SilkPolygon`：丝印图元。
- `SilkText`：丝印文字。
- `Bounds`：封装边界框。

主要职责：

- 创建 `R_0805`、`HEADER2_1`、`DIP14`、`SO14` 示例。
- 统一使用毫米。
- 计算封装边界。
- 序列化和反序列化，不直接依赖磁盘路径。

实验二应复用这一层，不要复制其中的焊盘结构。

### `src/FootprintCanvas.h/.cpp`

画布和交互层。

主要职责：

- 网格、坐标轴、缩放和平移。
- 绘制焊盘、钻孔、丝印和文本。
- 鼠标命中测试。
- 选择、拖动、删除。
- SMD 焊盘、THT 引脚、线、矩形、圆弧、多边形、文本的添加工具。
- 把毫米坐标转换为屏幕像素。

这一层只操作 `Footprint`，不负责打开文件对话框和元件库。

### `src/MainFrame.h/.cpp`

桌面应用层。

主要职责：

- 菜单、工具栏、元件库列表和属性面板。
- 新建、打开、保存、另存为。
- 扫描 `footprints/*.fp`。
- 第一次运行自动生成四个示例封装。
- 把界面输入写回数据模型。
- 管理未保存状态。

### `tests/model_roundtrip.cpp`

模型层自动化测试，验证：

- 示例封装的焊盘数量和间距。
- THT 钻孔和 1 脚标记。
- 保存再读取后数据不丢失。
- 边界框有效。

## 3. 实验一的数据边界

封装文件只保存“原型”：

```text
封装名称
参考点
焊盘和引脚
丝印图元
文字
单位
文件版本
```

封装文件不保存：

```text
板上实例位置
R1/U1/J1 位号
网络名称
走线
过孔
覆铜
```

后四项属于实验二。实验一只需要保证封装有稳定的名称和引脚编号。

## 4. 与实验二的接口

实验二读取 `.fp` 后，应该生成：

```cpp
struct ComponentInstance {
    std::string footprintName;
    std::string refdes;
    std::string value;
    double x;
    double y;
    double rotation;
    bool mirrored;
    std::unordered_map<std::string, std::string> pinToNet;
};
```

关键约束：

1. `footprintName` 与实验一封装名称一致。
2. `PadItem::number` 与原理图符号引脚编号一致。
3. 实验二保存实例位置和网络，不复制封装本体。
4. 旋转和镜像作用在整个实例上，不能只旋转显示。
5. 加载封装失败时，实验二应保留占位并给出错误，不要静默删除实例。

## 6. 报告建议写法

### 实验原理

重点写：

- 封装是物理焊盘和丝印的组合，不是逻辑门本身。
- THT 与 SMD 的区别。
- 坐标、参考点、栅格和单位。
- 原型与实例分离。

### 实验步骤

按下面顺序写：

1. 需求分析：列出封装编辑器和元件库功能。
2. 数据设计：画出 `Footprint -> PadItem / Silk*` 的类图。
3. 界面设计：说明左侧元件库、中间画布、右侧属性面板。
4. 交互设计：说明工具状态、鼠标事件和坐标转换。
5. 文件设计：贴出 `.fp` 格式示例。
6. 测试：使用 `tests/model_roundtrip.cpp` 和界面截图。

### 实验结果

至少放两张真实截图：

1. 主界面与 `DIP14` 或 `SO14` 封装。
2. 焊盘属性修改、另存为或元件库重新加载结果。

### 核心代码

只放这些：

- `PadItem` 和 `Footprint` 定义。
- `.fp` 保存和读取。
- 鼠标坐标转换与栅格吸附。
- 命中测试。
- 示例封装生成函数。

不要贴 wxWidgets 自动生成的窗口样板和全部事件绑定。
