# 当前代码框架导读

这份说明按当前实现讲，不要求重构成第一版的样子。

## 1. 程序从哪里开始

```text
App.cpp
  -> new MainFrame()
  -> MainFrame::MainFrame()
  -> BuildMenu()
  -> BuildLayout()
  -> library_.EnsureSamples()
  -> LoadLibrary()
```

对应位置：

- `src/App.cpp`
- `src/MainFrame.cpp` 的 `MainFrame::MainFrame()`

`App.cpp` 只负责创建主窗口，业务逻辑不要写在这里。

## 2. MainFrame 负责什么

`MainFrame` 是壳层和控制器，主要做四件事：

1. 创建菜单。
2. 创建左侧工具和元件库。
3. 创建中间 `FootprintCanvas`。
4. 创建右侧属性面板。

关键函数：

| 函数 | 作用 |
|---|---|
| `BuildMenu()` | 文件、编辑、视图、帮助菜单 |
| `BuildLayout()` | 左侧栏、画布、右侧属性的总布局 |
| `BuildToolPanel()` | 选择、SMD、THT、丝印等工具按钮 |
| `BuildLibraryPanel()` | 工具区、封装库列表和文件操作按钮 |
| `BuildPropertyPanel()` | 封装名称、分类、描述和焊盘属性 |

对应文件：

- `src/MainFrame.h`
- `src/MainFrame.cpp`

## 3. FootprintCanvas 负责什么

`FootprintCanvas` 是画布和交互层，不负责保存文件，也不负责扫描元件库。

关键函数：

| 函数 | 作用 |
|---|---|
| `SetFootprint()` | 把一个封装交给画布显示 |
| `SetTool()` | 切换选择、焊盘、引脚、丝印等工具 |
| `OnLeftDown()` | 处理鼠标左键 |
| `OnMotion()` | 拖动和更新坐标 |
| `OnMouseWheel()` | 缩放 |
| `OnPaint()` | 重绘整个画布 |
| `ModelToScreen()` | 毫米坐标转屏幕坐标 |
| `ScreenToModel()` | 屏幕坐标转毫米坐标 |
| `AddSmdPad()` | 添加 SMD 焊盘 |
| `AddThroughHolePin()` | 添加 THT 引脚 |
| `HitTest()` | 判断点击到了哪个对象 |
| `DrawPads()` | 绘制焊盘和钻孔 |
| `DrawSilkscreen()` | 绘制丝印图元 |

对应文件：

- `src/FootprintCanvas.h`
- `src/FootprintCanvas.cpp`

## 4. FootprintModel 负责什么

数据层只描述封装本身，不创建窗口、不弹对话框。

核心类型：

```text
Footprint
  ├─ PadItem
  ├─ SilkLine
  ├─ SilkRect
  ├─ SilkArc
  ├─ SilkPolygon
  └─ SilkText
```

关键函数：

| 函数 | 作用 |
|---|---|
| `GetBounds()` | 计算封装边界 |
| `Serialize()` | 封装转文本 |
| `Deserialize()` | 文本转封装 |
| `CreateResistor0805()` | 创建示例封装 |
| `CreateHeader2()` | 创建示例封装 |
| `CreateDip14()` | 创建示例封装 |
| `CreateSo14()` | 创建示例封装 |

对应文件：

- `src/FootprintModel.h`
- `src/FootprintModel.cpp`

## 5. FootprintLibrary 负责什么

它把“磁盘文件”与“封装对象”连接起来。

| 函数 | 作用 |
|---|---|
| `EnsureSamples()` | 元件库为空时生成示例 |
| `Reload()` | 扫描 `footprints/*.fp` |
| `Read()` | 从文件读取封装 |
| `Write()` | 把封装写入文件 |
| `Delete()` | 删除封装文件 |

对应文件：

- `src/FootprintLibrary.h`
- `src/FootprintLibrary.cpp`

## 6. 一次“放置焊盘”的完整流程

```text
点击左侧“SMD焊盘”
  -> MainFrame::SetTool(EditorTool::SmdPad)
  -> FootprintCanvas::SetTool()

点击画布
  -> FootprintCanvas::OnLeftDown()
  -> ScreenToModel()
  -> SnapToGrid()
  -> AddSmdPad()
  -> currentFootprint_.pads.push_back()
  -> MainFrame::OnCanvasDocumentChanged()
  -> Refresh()
  -> OnPaint()
  -> DrawPads()
```

理解这一条流程，就能理解大部分编辑功能。

## 7. 一次“保存封装”的完整流程

```text
点击保存
  -> MainFrame::SaveCurrent()
  -> SyncMetadataFromControls()
  -> Footprint::Serialize()
  -> FootprintLibrary::Write()
  -> LoadLibrary()
  -> 刷新左侧封装列表
```

## 8. 一次“切换封装”的完整流程

```text
点击左侧封装库条目
  -> MainFrame::OnLibrarySelected()
  -> FootprintLibrary::Read()
  -> currentFootprint_ = footprint
  -> FootprintCanvas::SetFootprint()
  -> RefreshProperties()
  -> FitView()
  -> Refresh()
```

## 9. 想修改 GUI 时改哪里

### 修改左侧工具区

改：

- `BuildToolPanel()`
- `BuildLibraryPanel()`
- `BuildLayout()`

### 修改右侧属性面板

改：

- `BuildPropertyPanel()`
- `RefreshProperties()`
- `OnApplyProperties()`

### 增加一个新工具

1. 在 `FootprintCanvas.h` 的 `EditorTool` 增加枚举。
2. 在 `BuildToolPanel()` 增加按钮。
3. 在 `OnLeftDown()` 增加工具分支。
4. 在模型里增加对应数据。
5. 在 `Draw*()` 增加绘制。
6. 在 `HitTest()` 增加命中判断。
7. 在 `Serialize()` / `Deserialize()` 增加文件字段。

### 修改画布交互

优先看：

- `OnLeftDown()`
- `OnLeftUp()`
- `OnMotion()`
- `OnMouseWheel()`
- `OnKeyDown()`

## 10. 和第一版的对应关系

| 第一版 | 当前实验一 |
|---|---|
| `App` | `App.cpp` |
| `MainFrame` | `MainFrame` |
| `DrawBoard` / `Canvas` | `FootprintCanvas` |
| `Schematic` | `Footprint` |
| `Component` | `PadItem` + 丝印图元 |
| `ShapeLibrary` | `FootprintLibrary` |
| `Wire` | 实验二再加入 |
| 逻辑仿真 | 封装属性和制造数据 |

所以当前代码仍然沿用第一版的基本思路：

```text
应用入口 -> 主窗口 -> 画布 -> 数据模型
```

只是画布里的数据从逻辑门换成了 PCB 封装。
