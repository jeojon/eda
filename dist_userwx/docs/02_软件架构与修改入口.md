# 实验一软件架构与修改入口

## 总体结构

```text
App.cpp
  └─ MainFrame
      ├─ 左侧工具按钮
      ├─ 左侧元件库列表
      ├─ FootprintCanvas
      │   └─ Footprint 数据模型
      ├─ 右侧属性面板
      └─ FootprintLibrary
          └─ footprints/*.fp
```

## 文件职责

| 文件 | 层级 | 职责 |
|---|---|---|
| `src/App.cpp` | 应用入口 | 创建并显示 `MainFrame` |
| `src/MainFrame.*` | 壳层/控制器 | 菜单、工具栏、元件库、属性面板、文件对话框 |
| `src/FootprintCanvas.*` | 视图/交互 | 画布、坐标转换、绘制、鼠标事件、命中测试 |
| `src/FootprintModel.*` | 数据层 | 封装、焊盘、丝印、边界和序列化 |
| `src/FootprintLibrary.*` | 持久化层 | 目录扫描、封装文件读写、示例生成 |
| `tests/model_roundtrip.cpp` | 测试 | 检查封装数据和保存加载 |

## 一次操作的调用链

### 放置一个 SMD 焊盘

```text
点击左侧“SMD焊盘”
  -> MainFrame::SetTool(EditorTool::SmdPad)
  -> Canvas::SetTool

点击画布
  -> FootprintCanvas::OnLeftDown
  -> ScreenToModel
  -> SnapToGrid
  -> AddSmdPad
  -> footprint.pads.push_back
  -> MainFrame::OnCanvasDocumentChanged
  -> Refresh
  -> OnPaint
```

### 保存封装

```text
MainFrame::SaveCurrent
  -> 从属性面板同步名称、分类、描述
  -> Footprint::Serialize
  -> FootprintLibrary::Write
  -> 刷新元件库列表
```

### 从元件库切换封装

```text
左侧列表选择
  -> MainFrame::OnLibrarySelected
  -> FootprintLibrary::Read
  -> currentFootprint_ = footprint
  -> FootprintCanvas::SetFootprint
  -> RefreshProperties
  -> FitView + Refresh
```

## 和第一版逻辑门编辑器的对应关系

第一版和第二版都采用 `App -> MainFrame -> Canvas -> Model` 的分层。

| 第一版 | 实验一第二版 |
|---|---|
| `Component` | `PadItem` + `Silk*` |
| `Schematic` | `Footprint` |
| `ShapeLibrary` | `FootprintLibrary` |
| 逻辑门放置 | 焊盘/引脚/丝印放置 |
| 导线 `Wire` | 实验二再加入 |
| 逻辑仿真 | 封装几何和制造属性 |
| `.txt` 原理图 | `.fp` 封装文件 |

保留的部分：

- wxWidgets 事件驱动。
- 左侧元件区 + 中间画布。
- 菜单和文件操作。
- 网格、缩放和平移。
- 数据模型与绘制分离。

替换的部分：

- 逻辑门对象换成封装对象。
- 逻辑仿真换成封装属性编辑。
- ShapeLibrary 换成文件系统 FootprintLibrary。

## 如何新增一种图元

例如新增“圆环”：

1. 在 `FootprintModel.h` 增加 `SilkRing`。
2. 在 `Footprint` 增加 `std::vector<SilkRing> rings`。
3. 在 `Serialize` / `Deserialize` 增加 `RING` 行。
4. 在 `GetBounds` 把圆环范围加入边界。
5. 在 `FootprintCanvas` 增加工具枚举和鼠标放置流程。
6. 在 `DrawSilkscreen` 增加绘制。
7. 在 `HitTest` 增加命中判断。
8. 在 `MainFrame` 增加按钮。

## 如何新增一种焊盘形状

1. 扩展 `PadShape`。
2. 修改文件的形状字段解析。
3. 在 `DrawPads` 增加绘制分支。
4. 在 `HitPad` 增加命中判断。
5. 属性面板增加形状选择。

## 实验二如何接入

实验二不要复制封装对象，而应使用：

```text
FootprintLibrary::Read(...)
ComponentInstance::footprintName
ComponentInstance::x, y, rotation
ComponentInstance::pinToNet
```

示例：

```cpp
Footprint libraryFootprint;
library.Read("footprints/DIP14.fp", libraryFootprint);

ComponentInstance u1;
u1.footprintName = "DIP14";
u1.refdes = "U1";
u1.x = 30.0;
u1.y = 20.0;
u1.rotation = 0.0;
u1.pinToNet["1"] = "GND";
u1.pinToNet["14"] = "+3.3V";
```

关键约束：

1. 封装名称稳定。
2. 引脚编号稳定。
3. 封装坐标是局部坐标。
4. 板上实例只保存位置、旋转、位号和网络。
5. 旋转和镜像作用于整个实例。
