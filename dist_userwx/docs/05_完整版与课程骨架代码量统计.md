## 4. 如何理解这些数字

216 行并不是最终需要写的逻辑量。它只是骨架中四个文件的函数声明、默认返回值和注释占位。实际补全时通常会写成更多行，尤其是：

- 焊盘旋转后的边界计算；
- 线段、矩形、圆弧和多边形的命中测试；
- `.fp` 格式的逐字段解析与错误处理；
- 文件库目录扫描、路径安全和原子写入；
- 你自己增加的测试。

界面已经占了完整实现的一大部分。课程骨架把界面保留下来，是为了让大家把时间集中在数据模型、几何、文件格式和实验二接口上；不应该通过重写整个 GUI 来完成实验。

## 5. 统计复现命令

在仓库根目录执行类似命令即可重新统计：

```powershell
$files = @(
  "src/App.cpp",
  "src/FootprintCanvas.cpp",
  "src/FootprintCanvas.h",
  "src/MainFrame.cpp",
  "src/MainFrame.h"
)
$files | ForEach-Object {
  [pscustomobject]@{
    File = $_
    Lines = (Get-Content $_).Count
  }
}
```

如果要严格比较不同版本，记得使用同一统计口径，并把测试代码单独列出，避免把生成代码和业务代码混在一起。
