# 实验要求对照表

本表依据课件《EDA 软件设计 I 实验》中“实验一 电路板元件封装的设计与管理”的要求逐条核对。

## 一、实验目的对照

| 课件要求 | 当前实现 | 位置 |
|---|---|---|
| 掌握元件封装设计的完整流程 | 新建、编辑、保存、重新加载、元件库复用 | `MainFrame.cpp`、`FootprintLibrary.cpp` |
| 理解封装对象如何聚合子对象 | `Footprint` 聚合焊盘、引脚、丝印和文字 | `FootprintModel.h` |
| 掌握焊盘和引脚属性 | 编号、名称、位置、尺寸、旋转、钻孔、阻焊、安全间距 | `PadItem`、属性面板 |
| 掌握基本图形元素交互 | 添加、选择、拖动、删除、网格吸附 | `FootprintCanvas.cpp` |
| 了解封装标准与保存加载 | 提供标准示例尺寸、版本化 `.fp` 文件 | 示例封装、`Serialize/Deserialize` |
| 本质是 PCB 封装实验，不是普通绘图 | 数据包含钻孔、阻焊、安全间距、图层和引脚编号 | `PadItem`、文件格式 |

## 二、实验内容对照

### 1. UI 和绘图区域

课件要求：

- 选择系统平台和 GUI SDK。
- 界面上有绘图工具按钮。
- 有中央绘图区域。

当前实现：

- Windows x64。
- wxWidgets 3.3.3，MSVC 编译。
- 左侧绘制工具。
- 中央画布。
- 右侧属性面板。
- 菜单和状态栏。

涉及函数：

- `MainFrame::BuildLayout`
- `MainFrame::BuildToolPanel`
- `MainFrame::BuildLibraryPanel`
- `MainFrame::BuildPropertyPanel`

### 2. 图形绘制

课件要求：

- 线段。
- 圆弧。
- 矩形。
- 多边形。
- 文本。
- 颜色、线宽等外观属性。
- 复合图形构成封装。
- 栅格对齐。

当前实现：

| 要求 | 状态 | 说明 |
|---|---|---|
| 线段 | 已实现 | `SilkLine` |
| 圆弧 | 已实现 | `SilkArc`，当前工具默认生成半圆弧 |
| 矩形 | 已实现 | `SilkRect` |
| 多边形 | 已实现 | 多次点击，右键结束 |
| 文本 | 已实现 | `SilkText` |
| 线宽 | 已实现 | 每个丝印图元保存线宽 |
| 颜色 | 已实现 | 封装保存丝印颜色，属性面板可填写 `#RRGGBB` 并作用于全部丝印图元 |
| 复合图形 | 已实现 | 一套封装聚合成多个子对象 |
| 栅格对齐 | 已实现 | `SnapToGrid` |

当前颜色按封装级丝印层统一管理，符合 PCB 丝印层通常使用统一颜色的实际习惯。

### 3. 电气与制造特征

课件要求：

- 引脚、焊盘安全间距。
- 阻焊开窗尺寸。
- 丝印线宽。

当前实现：

| 要求 | 状态 |
|---|---|
| 引脚/焊盘安全间距 | 已保存，并在画布上用红色长虚线显示 |
| 阻焊开窗 | 已保存，并在画布上用灰色点线显示 |
| 丝印线宽 | 已保存并参与绘制 |
| 钻孔尺寸 | THT 引脚支持 |
| 方形/圆形/圆角矩形焊盘 | 支持 |

### 4. 文件与元件库

课件要求：

- 封装文件保存。
- 封装文件加载。
- 元件库管理。

当前实现：

- 自定义 ASCII `.fp` 格式。
- 文件包含版本号、单位、名称、分类、描述和参考点。
- 元件按分类显示。
- 支持刷新、保存、另存为和删除。
- 启动时自动生成四个示例封装。

对应函数：

- `Footprint::Serialize`
- `Footprint::Deserialize`
- `FootprintLibrary::Reload`
- `FootprintLibrary::Read`
- `FootprintLibrary::Write`
- `FootprintLibrary::Delete`

## 三、当前实现满足的核心验收

1. SMD 封装编辑。
2. THT 封装编辑。
3. 焊盘和引脚编号。
4. 钻孔、阻焊和安全间距。
5. 五种丝印图元。
6. 封装文件保存和重新加载。
7. 分类元件库。
8. 网格吸附、缩放和平移。
9. 至少一个包含多引脚对象的 IC 封装。

## 四、可能被追问的地方

### 1. wxWidgets 不在课件示例列表

课件列出的示例是 `Win32`、`GDK`、`Qt`。当前程序使用 `wxWidgets`。

建议：

- 先确认老师是否允许 wxWidgets。
- 如果要求严格限定 SDK，可以保留数据模型，只替换界面框架。
- 当前 wxWidgets 是用户电脑已有安装，不是临时下载版本。

### 2. 没有自动 DRC

实验一保存了安全间距并可视化，但没有完整检查所有间距冲突。完整 DRC 更属于实验二或后续扩展。

### 3. 圆弧当前是半圆

模型支持任意起始角和扫掠角，但画布工具当前固定生成半圆弧。

## 五、建议报告表述

可以写：

> 本实验采用 wxWidgets 构建图形界面，使用 `wxGraphicsContext` 完成矢量绘制。封装数据模型采用毫米作为统一单位，将焊盘、引脚、丝印、文本和参考点聚合为 `Footprint` 对象。丝印颜色和线宽随封装保存，并参与实际绘制。SMD 焊盘仅包含表层铜箔和阻焊开窗，THT 引脚额外保存钻孔直径。每个焊盘保存安全间距，并在画布中以虚线显示，用于后续 DRC 和实验二布局布线使用。封装文件采用带版本号的 ASCII 格式，元件库从文件系统目录加载并支持增删和重新读取。
