# 实验要求对照

| 实验要求 | 骨架位置 |
|---|---|
| GUI 和绘图区域 | `src/gui/MainFrame.cpp` |
| SMD/THT 按钮 | `src/gui/MainFrame.cpp` |
| 画布和鼠标事件 | `src/gui/FootprintCanvas.cpp` |
| 数据对象 | `include/eda/FootprintTypes.h` |
| 封装对象聚合焊盘子对象 | `Footprint::pads` 等容器 |
| 焊盘、引脚、钻孔、阻焊、间距 | `PadItem` |
| 线、矩形、圆弧、多边形、文本 | `Silk*` 结构 |
| 栅格吸附 | `IGeometryService::SnapToGrid` |
| 选择/命中 | `IGeometryService::HitTest` |
| 文件保存加载 | `IFootprintCodec` |
| 文件系统元件库 | `IFootprintLibrary` |
| 具体实现 | `src/todo/` |

## 当前不包含的实现

课程骨架故意不实现：

- 文件格式解析。
- 元件库扫描。
- 几何计算。
- 编辑操作。

这些正是课程组需要自己完成的部分。
