# 零基础先看：PCB 封装到底是什么

## 一句话

**封装是元件焊在 PCB 板上的“安装模板”。**

它不是实际元件，也不是已经做好的电路板，更不是已经钻好的孔和贴好的焊锡。

## 这个软件到底在做什么

实验一的软件只是在电脑里描述下面这些信息：

```text
一个元件有几个脚
每个脚在板上的位置
每个焊盘多大
通孔要钻多大
两个脚之间隔多远
丝印外框画在哪里
1 脚标记在哪里
这个封装叫什么名字
```

它不会真的去钻板子，也不会真的去贴焊锡。

它输出的是一份**封装设计文件**。以后工厂或实验二读取这份文件，才知道焊盘和孔应该放在哪里。

## 你那个比喻应该怎么修正

你说：

> 相当于给你一块板子，然后钻好孔、贴好锡。

更准确的说法是：

> 相当于给软件一份施工图，说明以后钻孔应该钻在哪里、焊盘应该有多大、丝印应该画在哪里。

区别是：

| 实际 PCB | 实验一软件 |
|---|---|
| 一块真实的板子 | 一个数据模型 |
| 真的有孔 | 只保存钻孔直径和坐标 |
| 真的有铜焊盘 | 只保存焊盘形状和尺寸 |
| 真的印了丝印 | 只保存丝印线段和文字 |
| 真的加了焊锡 | 软件不负责焊锡 |

焊锡、锡膏、回流焊是 PCB 生产和组装阶段的事情，不是封装编辑器的功能。

## 三个必须分清的东西

### 1. 原理图符号

原理图画的是抽象功能，例如：

```text
电阻符号
电容符号
与门符号
```

它回答“电路里怎么连接”。

### 2. 实际元件

实际元件是买到的实物，例如：

```text
一个 0805 封装的 10 kΩ 电阻
一个 74HC00 逻辑芯片
一个两脚排针
```

它回答“买什么、参数是多少”。

### 3. PCB 封装

封装是实际元件在 PCB 上的物理落脚点，例如：

```text
R_0805
HEADER2_1
DIP14
SO14
```

它回答“这个实物怎么焊到板子上”。

## 板子上实际存在什么

一块加工完成的 PCB 通常有：

- 基板：板子的绝缘材料。
- 铜层：板子内部的导电铜。
- ==焊盘==：露出来用于焊接的铜区域。
- ==钻孔==：通孔元件和过孔需要的孔。
- 阻焊层：板子的绿油，焊盘位置会开窗。
- ==丝印层==：白色的元件轮廓、位号和说明文字。
- 走线：铜层上的导线。
- ==过孔==：连接不同铜层的孔。

实验一只设计封装中的：

- 焊盘。
- 钻孔。
- 丝印。
- 参考点。
- 封装名称和编号。

## SMD 和 THT

### SMD / SMT

贴片元件直接放在板子表面。

- 焊盘没有钻孔。
- 常见于电阻、电容、LED、贴片芯片。

### THT

通孔元件的脚穿过板子，再从背面焊接。

- 焊盘中心有钻孔。
- 常见于排针、DIP 芯片、大功率器件。

## 实验一最关键的几个字段

| 字段 | 含义 | 软件里怎么保存 |
|---|---|---|
| 编号 | 这个焊盘是 1 脚还是 2 脚 | 字符串，如 `1`、`A1` |
| 坐标 | 焊盘相对于封装原点的位置 | 毫米 |
| 宽度 | 焊盘横向尺寸 | 毫米 |
| 高度 | 焊盘纵向尺寸 | 毫米 |
| 钻孔 | THT 孔直径 | 毫米 |
| 阻焊扩展 | 焊盘外阻焊开窗再扩多少 | 毫米 |
| 安全间距 | 与其他铜对象的最小距离 | 毫米 |
| 参考点 | 封装的局部坐标原点 | 一个坐标 |

## 为什么实验一不需要模拟电路知识

实验一不会计算：

- 电压。
- 电流。
- 放大倍数。
- 滤波器截止频率。
- 晶体管工作点。

实验一实现的是软件问题：

- 怎么定义对象。
- 怎么绘制。
- 怎么命中测试。
- 怎么拖动。
- 怎么保存和读取。
- 怎么管理元件库。

所以你是软件工程学生，做这个实验并不吃亏，反而主要用的就是软件工程能力。
