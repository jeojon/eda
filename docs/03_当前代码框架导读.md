## 6. 一次“放置焊盘”的完整流程

```text
点击左侧“SMD焊盘”
  -> MainFrame::SetTool(EditorTool::SmdPad)
  -> FootprintCanvas::SetTool()

点击画布
  -> FootprintCanvas::OnLeftDown()
  -> ScreenToModel()
  -> SnapToGrid()
  -> AddSmdPad()
  -> currentFootprint_.pads.push_back()
  -> MainFrame::OnCanvasDocumentChanged()
  -> Refresh()
  -> OnPaint()
  -> DrawPads()
```

理解这一条流程，就能理解大部分编辑功能。

## 7. 一次“保存封装”的完整流程

```text
点击保存
  -> MainFrame::SaveCurrent()
  -> SyncMetadataFromControls()
  -> Footprint::Serialize()
  -> FootprintLibrary::Write()
  -> LoadLibrary()
  -> 刷新左侧封装列表
```

## 8. 一次“切换封装”的完整流程

```text
点击左侧封装库条目
  -> MainFrame::OnLibrarySelected()
  -> FootprintLibrary::Read()
  -> currentFootprint_ = footprint
  -> FootprintCanvas::SetFootprint()
  -> RefreshProperties()
  -> FitView()
  -> Refresh()
```

## 10. 和第一版的对应关系

| 第一版 | 当前实验一 |
|---|---|
| `App` | `App.cpp` |
| `MainFrame` | `MainFrame` |
| `DrawBoard` / `Canvas` | `FootprintCanvas` |
| `Schematic` | `Footprint` |
| `Component` | `PadItem` + 丝印图元 |
| `ShapeLibrary` | `FootprintLibrary` |
| `Wire` | 实验二再加入 |
| 逻辑仿真 | 封装属性和制造数据 |

所以当前代码仍然沿用第一版的基本思路：

```text
应用入口 -> 主窗口 -> 画布 -> 数据模型
```

只是画布里的数据从逻辑门换成了 PCB 封装。
