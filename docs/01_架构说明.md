# 架构说明

## 总体分层

```text
App
└─ MainFrame（GUI 壳层）
   ├─ 工具按钮
   ├─ 元件库列表
   ├─ FootprintCanvas（画布）
   └─ 属性面板

FootprintCanvas
├─ IFootprintEditor     编辑逻辑
├─ IGeometryService     几何/命中逻辑
└─ Footprint           纯数据结构

MainFrame
├─ IFootprintCodec     文件编解码
└─ IFootprintLibrary   文件系统元件库
```

## 目录职责

| 目录 | 职责 |
|---|---|
| `include/eda/FootprintTypes.h` | 数据结构，不包含业务逻辑 |
| `include/eda/I*.h` | 稳定接口 |
| `src/gui/` | wxWidgets 界面和鼠标交互 |
| `src/todo/` | 需要自行实现的逻辑 |
| `footprints/` | 元件库文件 |
| `docs/` | 文档 |

## 依赖方向

```text
GUI -> Interface -> Data Types
```

GUI 可以调用接口，但不能重新实现文件格式、几何算法或元件库扫描。这样以后换界面时，逻辑不用重写。

## 一次放置 SMD 焊盘的过程

```text
MainFrame 设置工具为 SmdPad
  -> FootprintCanvas::OnLeftDown
  -> ScreenToModel
  -> IGeometryService::SnapToGrid
  -> IFootprintEditor::AddSmdPad
  -> 数据进入 Footprint.pads
  -> 通知 MainFrame 数据已变化
  -> Refresh
```

## 一次保存的过程

```text
MainFrame::SaveCurrent
  -> 同步名称、分类、描述和颜色
  -> IFootprintLibrary::Write
       -> IFootprintCodec::Serialize
       -> 写文件
```

## 一次打开的过程

```text
元件库列表选择
  -> IFootprintLibrary::Read
       -> 读文件
       -> IFootprintCodec::Deserialize
  -> currentFootprint_
  -> FootprintCanvas::SetFootprint
  -> 属性面板刷新
```
