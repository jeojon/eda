# 接口说明

## IFootprintEditor

只负责编辑数据对象，不处理鼠标、窗口和文件。

主要方法：

- `AddSmdPad`
- `AddThroughHolePin`
- `AddLine`
- `AddRect`
- `AddArc`
- `AddPolygon`
- `AddText`
- `UpdatePad`
- `MovePad`
- `RemoveItem`

## IGeometryService

只负责纯几何计算。

主要方法：

- `ComputeBounds`
- `HitTest`
- `SnapToGrid`

## IFootprintCodec

只负责内存对象和文本之间的转换。

主要方法：

- `Serialize`
- `Deserialize`

不负责打开文件对话框，也不负责遍历目录。

## IFootprintLibrary

只负责文件系统中的封装库。

主要方法：

- `DefaultDirectory`
- `Reload`
- `Entries`
- `Read`
- `Write`
- `Delete`

它会调用 `IFootprintCodec`，但不关心 GUI。

## 设计约束

1. 数据结构使用毫米。
2. 封装保存局部坐标。
3. GUI 不直接解析文件。
4. 接口不依赖 wxWidgets 控件。
5. 实验二只保存封装 ID、实例位号、板上位置、旋转和网络。
