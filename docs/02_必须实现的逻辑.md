# 必须实现的逻辑

## 1. 封装编辑逻辑

文件：

```text
src/todo/FootprintEditorService.cpp
```

需要实现：

- 添加 SMD 焊盘。
- 添加 THT 引脚。
- 自动分配引脚编号。
- 添加线段、矩形、圆弧、多边形和文本。
- 修改焊盘属性。
- 移动焊盘。
- 删除焊盘或丝印对象。

验收例子：

```text
点击 SMD 焊盘工具并点击画布
-> Footprint.pads 多出一个焊盘
-> 编号自动变成 1、2、3...
```

## 2. 几何和命中测试

文件：

```text
src/todo/GeometryService.cpp
```

需要实现：

- 计算整个封装的边界框。
- 判断鼠标是否点中焊盘。
- 判断鼠标是否点中线、矩形、圆弧、多边形和文字。
- 栅格吸附。

注意：

- 全部使用毫米。
- 命中容差由调用者传入。
- 多边形按边距离判断，而不是只看包围盒。

## 3. 封装文件编解码

文件：

```text
src/todo/FootprintCodec.cpp
```

需要实现：

- 把 `Footprint` 转成文本。
- 从文本恢复 `Footprint`。
- 校验文件版本和单位。
- 保存名称、分类、描述、丝印颜色、参考点。
- 保存所有焊盘、引脚和丝印对象。
- 保存钻孔、阻焊扩展和安全间距。

建议格式：

```text
EDALAB1_FOOTPRINT 1
NAME R_0805
CATEGORY Passive
DESC 0805 SMD land pattern
SILKCOLOR #1A6984
ORIGIN 0 0
PAD SMD ROUNDED 1 1 -0.9 0 1.3 1.5 0 0 0.1 0.2
LINE -0.5 -0.8 0.5 -0.8 0.12
TEXT 0 1.1 0.8 R?
END
```

## 4. 文件系统元件库

文件：

```text
src/todo/FilesystemFootprintLibrary.cpp
```

需要实现：

- 扫描 `footprints/*.fp`。
- 通过 `IFootprintCodec` 读取每个封装。
- 建立封装条目列表。
- 写入新封装。
- 删除封装。
- 为实验二提供稳定封装接口。
