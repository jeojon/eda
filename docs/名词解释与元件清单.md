# EDA 实验一：元件清单、封装参数与功能说明

## 零基础先理解：PCB 封装到底在干什么

### 一句话解释

**封装就是元件焊在电路板上的“脚印”和“落脚点”。**

它不是电阻的阻值，也不是芯片内部功能，而是描述：

- 元件在板子上占多大地方。
- 有几个脚需要焊。
- 每个脚的位置在哪里。
- 每个焊盘多大。
- 通孔元件的孔钻多大。
- 元件外框和 1 脚标记画在哪里。

### 三个东西不要混在一起

以电阻为例：

```text
原理图符号：一个长方形符号，表示“这里有一个电阻”
实际元件：  一个真实的贴片电阻，例如 0805 封装
PCB 封装：  板子上的两个焊盘、间距和丝印位置
```

以逻辑芯片为例：

```text
Logisim 中的与非门：逻辑功能
真实芯片 74HC00：  一个包含四个与非门的芯片
PCB 封装 DIP14：    一个 14 脚的物理封装
```

所以，同一个逻辑门在 Logisim 里可能是一个符号，在 PCB 上却是一个真实的芯片封装。封装编辑器不关心“这个门做什么”，只关心“这个芯片怎么焊到板子上”。

### 实验一为什么不需要模拟电路基础

实验一的重点是软件和数据结构：

- 怎么表示一个焊盘。
- 怎么表示一个封装。
- 鼠标点击后怎么画出来。
- 怎么保存成文件。
- 怎么从元件库重新加载。

不需要计算电压、电流、放大倍数，也不需要设计模拟电路。你只要把封装当成“有尺寸的图形对象”即可。

### 实验一到底在做什么

可以把它理解成一个专门画“元件脚位模板”的小画图软件：

1. 新建一个封装。
2. 放两个 SMD 焊盘。
3. 把焊盘编号设成 1 和 2。
4. 调整两个焊盘的距离。
5. 画一个丝印外框。
6. 设定参考点。
7. 保存为封装文件。
8. 再从元件库里把它加载出来。

实验二才会把这种封装放到 PCB 板上，拖动、布局、连线。

### 必须先懂的几个词

| 名词 | 通俗解释 |
|---|---|
| PCB | 电路板本身 |
| 元件 | 电阻、电容、芯片、排针等真实零件 |
| 封装 / Footprint | 元件在 PCB 上的焊盘和外形模板 |
| 焊盘 / Pad | 板上露出的铜区域，用来焊元件脚 |
| 引脚 / Pin | 元件上的脚，或者通孔封装里的金属孔 |
| 钻孔 / Drill | THT 元件引脚穿过板子时钻的孔 |
| 丝印 / Silkscreen | 板子上的白色文字和轮廓 |
| 阻焊 / Solder Mask | 板子的绿油层，焊盘处会开窗 |
| 阻焊扩展 / Mask Expansion | 焊盘周围阻焊层再向外让出的距离 |
| 安全间距 / Clearance | 两个铜对象之间必须保留的距离 |
| 参考点 / Origin | 封装自己的坐标原点 |
| 位号 / Reference | `R1`、`C1`、`U1`、`J1` 这类编号 |
| 元件值 / Value | `10 kΩ`、`100 nF`、`AMS1117-3.3` 这类参数 |
| 层 / Layer | 顶层、底层、丝印层、阻焊层等逻辑层 |
| 走线 / Track | 板上连接两个焊盘的铜线 |
| 过孔 / Via | 连接不同铜层的金属孔 |
| 网络 / Net | 逻辑上应该连在一起的一组引脚 |
| DRC | 检查间距、短路、断路等设计规则 |
| Gerber | 交给 PCB 工厂生产用的制造文件 |

### SMD 和 THT 是什么

**SMD / SMT：贴片元件**

- 元件直接贴在板子表面。
- 焊盘没有钻孔。
- 电阻、电容、LED 常见这种形式。
- 例子：`R_0805`、`SO14`。

**THT：通孔元件**

- 元件引脚穿过板子，再从背面焊接。
- 焊盘中间有钻孔。
- 排针、DIP 芯片、大功率器件常见这种形式。
- 例子：`HEADER2_1`、`DIP14`。

### 0805、0603、0402 是什么

这些是贴片元件的尺寸代号，主要表示元件本体大小：

| 代号 | 本体大约尺寸 |
|---|---|
| `0402` | 约 1.0 × 0.5 mm |
| `0603` | 约 1.6 × 0.8 mm |
| `0805` | 约 2.0 × 1.25 mm |
| `1206` | 约 3.2 × 1.6 mm |

注意：`0805` 不是焊盘尺寸，也不是电阻值，只是元件大小代号。

### DIP14、SO14 是什么

- `DIP14`：双列直插，14 个通孔引脚。
- `SO14`：小外形贴片，14 个表面贴装引脚。

`14` 表示有 14 个脚。`DIP` 和 `SO` 表示封装的外形和焊接方式。

### 实验一最需要做的四个封装

1. `R_0805`：让你理解最简单的 SMD 两焊盘封装。
2. `HEADER2_1`：让你理解 THT 引脚、钻孔和 2.54 mm 间距。
3. `DIP14`：让你理解多引脚通孔 IC 和 1 脚方向。
4. `SO14`：让你理解多引脚贴片 IC 和 1.27 mm 小间距。

做完这四个，PCB 封装的基本概念和软件功能就都覆盖到了。

## 先说明三件事

### 1. 实验一要的是“封装”，不是逻辑功能

Logisim 里的与门、或门是功能概念。到了 PCB 上，一个 74HC00 芯片可能就是一个 DIP-14 或 SOIC-14 封装。实验一只需要描述：

- 这个器件在 PCB 上占多大空间。
- 有几个焊盘或引脚。
- 每个焊盘在哪里。
- 焊盘多大，钻孔多大。
- 丝印轮廓在哪里。
- 引脚编号是什么。

封装编辑器不需要知道芯片内部有几个逻辑门。

### 2. 电气值和封装值不是一回事

例如：

```text
R_0805      是封装
R1          是元件实例位号
10 kΩ       是元件实例的电气参数值
```

同一个 `R_0805` 封装可以对应 0 Ω、10 kΩ、100 kΩ 等不同电阻。实验一保存封装，实验二或 BOM 才保存具体值和位号。

### 3. 课件没有硬性规定必须做哪几个元件

课件规定的是功能范围：

- 能表达 SMD 焊盘。
- 能表达 THT 引脚和钻孔。
- 能表达焊盘、引脚、丝印和参考点。
- 能保存封装并管理元件库。

为了让实验一能独立验收，并顺利接到实验二，建议至少做下面 4 个封装。下面给出的值可以直接用于课程实现。

## 推荐元件清单

| 序号 | 封装名 | 类别 | 类型 | 参考位号 | 主要用途 |
|---|---|---|---|---|---|
| 1 | `R_0805` | 电阻/电容 | SMD | `R?` | 验证普通贴片焊盘 |
| 2 | `HEADER2_1` | 连接器 | THT | `J?` | 验证通孔、钻孔和 2.54 mm 间距 |
| 3 | `DIP14` | 逻辑 IC | THT | `U?` | 验证多引脚 IC、1 脚标记和双列排布 |
| 4 | `SO14` | 逻辑 IC | SMD | `U?` | 验证高密度贴片 IC 和 1.27 mm 间距 |

这 4 个已经覆盖了实验一最重要的类型，不需要一开始就做 QFP、BGA 或非常复杂的连接器。

### 丝印和文本


```text

```

### 说明

### 丝印和 1 脚标记

建议丝印轮廓：

## 实验一必须实现的功能

### 1. 封装数据模型

- `Footprint` 表示一个完整封装。
- `PadItem` 表示 SMD 焊盘或 THT 引脚。
- 丝印线、矩形、圆弧、多边形和文本独立存储。
- 封装有名称、描述、参考点、单位和文件版本。
- 封装内部使用局部坐标。

### 2. 图形界面

- 主菜单。
- 工具栏。
- 元件库列表。
- 绘图区域。
- 属性面板。
- 状态栏显示坐标、缩放和当前工具。

### 3. 图形编辑

- 绘制线段。
- 绘制矩形。
- 绘制圆弧。
- 绘制多边形。
- 添加文本。
- 修改颜色和线宽时可以只保留默认线宽，但数据结构应支持线宽。

### 4. 焊盘和引脚

- 添加 SMD 焊盘。
- 添加 THT 引脚。
- 修改编号和名称。
- 修改坐标、宽、高、旋转。
- 修改钻孔直径。
- 修改阻焊开窗。
- 修改安全间距。
- 支持圆形、方形、圆角矩形。

### 5. 交互

- 选择。
- 拖动。
- 删除。
- 网格吸附。
- 缩放。
- 平移。
- 适配画布。

### 6. 文件

- 新建封装。
- 保存为 `.fp`。
- 重新打开后数据不丢失。
- 文件有版本号。
- 文件有单位声明。
- 文件字段顺序固定，便于解析。

### 7. 元件库

- 扫描 `footprints/*.fp`。
- 显示封装列表。
- 点击后加载到画布。
- 支持刷新。
- 支持删除封装文件。
- 支持另存为新的封装文件。

## 实验一不用急着做的内容

下面属于实验二或后续增强：

- 网表导入。
- 飞线。
- PCB 板框。
- 层组管理。
- 走线。

```text
间距覆盖: 1.27 mm、2.54 mm
钻孔覆盖: 0.711 mm、0.965 mm

元件库: 文件系统目录 + 封装列表
```

## 最终建议

如果时间有限，优先顺序是：

1. `R_0805`：先跑通 SMD 焊盘、属性编辑和保存加载。
2. `HEADER2_1`：跑通 THT 引脚和钻孔。
3. `DIP14`：跑通 14 个引脚、1 脚标记和元件库。
4. `SO14`：证明同一个编辑器可以处理高密度贴片 IC。

这四个封装做完，实验一的功能范围就完整了。编码实现本身确实不是最大难点，真正的难点是把“封装名、参考点、焊盘编号、间距、钻孔、阻焊和安全间距”定义成统一、可保存、可被实验二复用的数据。
